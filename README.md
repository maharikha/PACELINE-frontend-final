# Paceline Frontend Task

Responsive two-page Paceline running shop website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home / shop
- `about.html` — Our Story

## Highlights
- Responsive desktop/tablet/mobile layout
- Accessible skip link, labels and keyboard-friendly controls
- Functional mobile navigation
- Product category filters
- Wishlist toggle
- Demo shopping cart drawer with live item count and subtotal
- Newsletter success state
- Scroll reveal animations with reduced-motion support
- Hover interactions and polished micro-interactions
- No backend required

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deployment
This is a static site and can be deployed directly through Vercel, Netlify, or Firebase.


## External product imagery
Distinct product imagery is used in the New Arrivals cards for visual variety.

- Dedicated Men's Running and Women's Running collections with separate product sets


### Collection imagery
The Men's and Women's running collections use eight separate local product images (four per collection), sized with object-fit contain for a clean ecommerce layout.
